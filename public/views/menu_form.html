补充说明：
1. table / tables 是表格配置，chart / charts 是图表配置。
2. alarm.type 对应系统里的 notify.xxx 配置，报表块需产出 message 才会触发通知。
3. join / union 用于把多段 SQL 拼成一个报表块。
4. edit 用于可编辑报表，需配合 ddy_register_form_handler()。

语法说明

${name|label|default|type} name: 控件名称，需要是字母、数字、下划线组成
label: 控件的标签
default: 默认值，常量或时间表达式，例：today,yesterday,first day of this month
type:

  • date / date.month：日期 / 月份
  • time / time.hour：时间 / 小时
  • date_range / time_range：范围控件，会生成 from_xxx、to_xxx 宏
  • string：字符串
  • number / number.multiple：数字 / 数字列表
  • enum / enum.multiple：枚举下拉 / 多选
  • bool：布尔复选框
  • combine：拼接多个已有控件值，不单独渲染控件
  • br：仅用于换行布局
常见 flag： macro、raw、multiple、month、hour
常见示例： 
${date|日期|-7 days,today|date_range.macro.raw(range:31)}
${uid|UID||string.macro.raw}
${status|状态|1|enum(1:成功,0:失败)}
${business|业务类型|0|enum.macro.raw(ddy_page_business_type)}
SQL 注释配置： 
-- @id=报表标题
-- @dsn=default
-- @chart=__auto__
-- @chart=line:consume_amount,refund_amount
-- @plugin_sum={"sum":true,"avg":true}
-- @plugin_delay_series={"xAxis":"stat_date","series":["event_type"],"series_value":["event_count"]}
-- @invisible=true
表插件： plugin_filter、plugin_sort、plugin_flip、plugin_sum、plugin_series、plugin_date_line、plugin_data_fluctuations
字段插件： ratio、date、time2str、enum，也支持自定义 ddy_field_xxx()
列注释示例： 
request AS "Request", -- @{"json_display": true}
uid AS "UID", -- @{"href":"/#/report/38?query=uid={uid}"}
click/pv*100 AS "点击率", -- @{点击}/{曝光}*100
动态报表扩展：
1. ddy_set_page_data()：PHP 直接输出报表块
2. ddy_dynamic_reports()：运行时追加报表块
3. ddy_process_result()：最终结果统一后处理
4. #!MARKDOWN / #!RAW：显式指定输出模式
可编辑报表：
配合 options.edit、ddy_register_form_handler()、ddy_save_form_handler() 使用。
自定义筛选控件：
1. 用 enum(...ddy_xxx) 让 PHP 实时返回枚举选项
2. 自定义 Filter 类并通过 FilterFactory::register() 注册

真实模板示例

1. 日期范围 + 枚举映射统计 

${date|日期|-7 days,today|date_range.macro.raw(range:31)};

-- @id=渠道消耗
SELECT
    channel AS Channel,      -- @{"enum":"1:aibub"}
    channel_id AS "渠道类型", -- @{"enum":"1:中转1,2:中转2,4:微软4,5:微软5"}
    model_value,
    SUM(consume_amount) AS consume_amount
FROM user_api_call_record
WHERE created_at BETWEEN '{from_date} 00:00:00' AND '{to_date} 00:00:00'
GROUP BY channel, channel_id, model_value;
2. 趋势图 + plugin_delay_series 
-- @id=每天分事件数据
-- @plugin_delay_series={"xAxis":"time_date","series":["event_type"],"series_value":["event_count"]}
-- @chart=__auto__
-- @invisible=true
SELECT
    DATE_FORMAT(transaction_time, '%Y-%m-%d') AS time_date,
    event_type,
    COUNT(*) AS event_count
FROM card_transaction
GROUP BY time_date, event_type
ORDER BY time_date DESC;
3. PHP 宏推导 + 多报表块联查 
${card_id|card_id||string.macro.raw};
${card_last4|card_last4||string.macro.raw};

<?php
$card_id = ddy_data('card_id');
$card_last4 = ddy_data('card_last4');
if ($card_id) {
    ddy_macro('real_card_id', $card_id, false);
}
if ($card_last4) {
    $row = ddy_model('card', 'corpay')->select(['card_number_last4' => $card_last4]);
    if ($row && count($row)) {
        ddy_macro('real_card_id', $row[0]['card_id'], false);
    }
}
?>

-- @id=card
-- @plugin_flip=true
-- {?real_card_id}
SELECT * FROM card WHERE card_id = '{real_card_id}';
